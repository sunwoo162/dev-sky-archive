TREASURE MAP ASSET BOARD / 01

먼저 나누고,
그 다음에 조합한다.

지금 보는 건 2D 섬 월드가 아니다. 첫 화면 보물지도에 들어갈 그림 에셋만 따로 분해한 보드다. 네가 방향을 확인한 뒤에만 최종 지도에 조합한다.

현재 범위: 보물지도 첫 화면만 · 제외: 2D 섬 내부, 작업 캐릭터, AI 진행 화면 · 기준: 네가 보낸 오래된 보물지도의 갈색 선화와 밀도

PAPER / FRAME

BASE LAYER

01 / PAPER + BORDER

화면 전체를 감싸는 종이·프레임. UI 카드처럼 보이지 않게 먼저 깐다.

02 / PAPER GRAIN

거친 필터가 아니라 얇은 선과 얼룩만 넣어서 그림이 살아있는 종이처럼 보이게 한다.

03 / CARTOGRAPHY

대륙 뒤에 얇게 깔리는 지도선. 장식은 되지만 내용보다 앞에 나오지 않는다.

CONTINENT / TERRAIN

ORGANIC SHAPES

04 / CONTINENT SILHOUETTE

카테고리 건물을 얹기 전에 지도 몸체가 먼저 보이도록 만든다.

05 / MOUNTAIN RANGE

기본 삼각형 아이콘이 아니라 능선·눈선·겹선을 가진 지도용 산맥.

06 / WATER + COAST

대륙 외곽의 해안선과 바깥 파도. 땅과 바다의 밀도를 같이 만든다.

ROUTE / SIGNPOST

EXPLORATION LAYER

07 / DOTTED ROUTE

카테고리를 기계적으로 연결하지 않고, 지도를 가로지르는 탐험 동선으로 그린다.

08 / SIGNPOST

이름을 박스에 띄우는 대신 실제 지도 표식처럼 보이게 하는 방향 표지판.

09 / TREASURE MARK

빨간 보물 표시는 적게 사용해서 루트의 목적지를 강조한다.

LANDMARK INK

HAND-DRAWN DECORATION

10 / HOT-AIR-BALLOON

지도 위 빈 공간을 채우는 큰 장식. 카테고리 UI와 분리된 배경 그림이다.

11 / LIGHTHOUSE + CASTLE

오른쪽 끝 랜드마크와 중앙 섬의 상징물. 건물 UI가 아니라 지도 삽화로 사용한다.

12 / SHIP + PALM

하단 여백을 채우는 배와 야자수. 지도 전체를 여행지처럼 묶어주는 에셋이다.

COMPASS / TREASURE

FINISHING MARKS

13 / COMPASS ROSE

작은 방향 UI가 아니라 지도 일러스트의 한 부분으로 그린다.

14 / CLOUD + WAVE

구름과 파도는 화면을 채우되 대륙·랜드마크보다 얇게 둔다.

15 / LABEL PLATE

현재처럼 카드가 떠 보이지 않도록 종이 표식으로 통일한다.

COMPOSITION PREVIEW
