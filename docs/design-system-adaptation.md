# 디자인 시스템 적용 기록

## 선택한 기준

`oh-my-design`의 카드들을 실제 상세 페이지까지 확인한 뒤, 게임 포트폴리오와 가장 가까운 **NC / NCSOFT** 디자인 시스템을 기준으로 선택했다. NC의 게임 포털과 NC PLAY 미디어 화면은 게임 키아트를 먼저 보여주고, 인터페이스는 절제된 상태로 남겨두며, 카드 카탈로그와 제작 과정 문서를 한 시스템 안에서 함께 다룬다.

보물지도, 지도 위의 손그림, 픽셀 에셋은 프로젝트 고유 세계관이므로 교체하지 않았다. NC의 원본 로고·이미지·폰트 파일을 복사하는 대신, `Dev Sky Archive`에 맞게 다음 원칙만 변환했다.

- 지도/게임 화면은 작품이 먼저 보이는 full-bleed 구성으로 유지한다.
- 프로젝트 인덱스와 자료 카드는 흰색 카드, 16px radius, 얕은 구분선으로 정리한다.
- 인터랙션 색상은 NC Purple 계열 하나로 제한한다.
- 프로젝트 전시는 어두운 게임 히어로와 밝은 문서형 자료 영역이 이어지는 구조로 만든다.
- 그림자보다 명도 밴딩·hairline·카드 간격으로 깊이를 만든다.

## 코드 매핑

| 역할 | 적용 위치 | 적용한 규칙 |
| --- | --- | --- |
| navigation | 상단 상태 바 | 어두운 게임 캔버스 위 절제된 navigation chrome |
| status-surface | 최단 경로 항해 화면 | 현재 상태·경로·진행률을 하나의 게임 HUD로 정리 |
| index | 섬 우측 프로젝트 목록 | NC 게임 카드처럼 16px 카드와 보라색 선택 상태 |
| museum-guide | 섬 전시관 도슨트 모달 | 게임 화면 위에 흰색 문서형 필드 노트를 열고, 전체 전시로 이어지는 단일 CTA 제공 |
| dossier | 프로젝트 전시 화면 | 어두운 키아트 영역과 밝은 자료 카탈로그를 연결 |

## 토큰

`src/styles.css`의 `--ui-*` 토큰은 원본 브랜드를 복사한 값이 아니라, NC의 게임 포털/미디어 원칙을 이 프로젝트의 네이비·금색·양피지 팔레트에 맞춰 변환한 값이다.

- `--ui-canvas`, `--ui-foreground`, `--ui-muted`, `--ui-hairline`: NC PLAY형 어두운 작업면 계층
- `--ui-primary`, `--ui-primary-strong`, `--ui-primary-soft`: 단일 인터랙션 색상
- `--ui-control-radius`, `--ui-card-radius`, `--ui-tile-radius`: 6/16/12px 컴포넌트 반경
- `--ui-card-shadow`: 그림자 없이 명도와 hairline으로 구분하는 카드 elevation

## 에셋·라이선스 경계

이번 링크는 이미지 에셋 마켓이 아니라 실제 제품의 `DESIGN.md`를 정리한 아카이브다. 따라서 NC의 로고·게임 키아트·폰트 파일을 프로젝트에 복사하지 않고, 공개된 디자인 원칙과 측정된 UI 구조만 참고했다. 지도와 픽셀 에셋은 현재 레포의 로컬 에셋을 계속 사용한다.
