# 자료 보관함 문서 리더 디자인

## 목표

보물지도와 탐방 월드의 기존 시각 방향은 유지하고, 프로젝트 전시 안에 있는 `자료 보관함`을 실제로 열람할 수 있는 문서 영역으로 만든다. 현재 사용자 자료가 아직 없는 상태이므로 사실을 새로 만들어내지 않고 `임시 초안`임을 명확하게 표시한다.

## 범위

- 랜딩 보물지도, 양피지 색감, 선화, 나침반, 점선 경로, 랜드마크 배치는 변경하지 않는다.
- 프로젝트 전시의 8개 자료 슬롯을 클릭 가능한 문서 카드로 만든다.
- 카드 선택 시 같은 페이지 아래에 문서 리더를 펼친다.
- 문서 리더에는 문서 종류, 프로젝트 연결 정보, 임시 본문, 실제 자료 교체 안내를 표시한다.
- 닫기 버튼, `Escape`, 키보드 포커스 복귀를 지원한다.
- 현재 `project-records.json`과 전시 데이터에 있는 요약·역할·스택·타임라인만 근거로 사용한다.

## 선택한 상호작용

1. 인라인 문서 리더 — 추천
   - 탐방 흐름을 끊지 않고 카드와 문서를 한 화면에서 비교할 수 있다.
   - 정적 GitHub Pages 구조와 잘 맞고 별도 라우팅이 필요 없다.
2. 전체 모달 리더
   - 몰입감은 높지만 모달 포커스 트랩과 닫힘 상태 관리가 추가된다.
3. URL/hash 문서 페이지
   - 문서 링크 공유에는 좋지만 현재 정적 전시 구조에 비해 라우팅 복잡도가 커진다.

## 문서 종류

`SCREEN`, `SYSTEM`, `ROLE`, `EVIDENCE`, `PORTFOLIO`, `SELFINTRO`, `PROJECT`, `OTHER`를 유지한다. 각 종류는 독립 카드와 임시 문서 본문을 가지며, 실제 캡처·README·PR·자소서·이력서가 전달되면 해당 본문만 교체할 수 있어야 한다.

## 접근성 및 사실성

- 카드가 `button`이므로 키보드로 열 수 있어야 한다.
- 리더는 `aria-live="polite"`를 사용하고 제목을 제공한다.
- 닫은 뒤 마지막으로 선택한 카드에 포커스를 돌려준다.
- 임시 문서에는 `임시 초안`과 `실제 자료로 교체` 문구를 표시한다.
- 개인 역할, 성과, 수치는 현재 데이터에 없는 경우 추정하지 않는다.
