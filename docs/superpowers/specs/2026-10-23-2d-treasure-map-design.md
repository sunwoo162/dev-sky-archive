# 2D 보물지도 월드맵 디자인

## Intent

현재 첫 화면의 3D 하늘섬은 카메라·고도·플랫폼이 먼저 보여서 포트폴리오 카테고리와 탐방 흐름이 한눈에 읽히지 않는다. 첫 화면을 오래된 보물지도처럼 보이는 2D 월드맵으로 바꾸고, 카테고리 랜드마크를 클릭하면 기존 상세 2D 탑다운 프로젝트 월드로 진입하게 한다.

## User experience

- 첫 화면은 1200×760 기준의 반응형 양피지 지도다.
- 지도에는 프로필, 개인 프로젝트, 팀 프로젝트, 대외활동, 스터디를 각각 하나의 랜드마크로 배치한다.
- 산맥, 해안선, 섬, 등대, 성, 항구, 도서관 등은 카테고리의 의미를 전달하는 장식과 랜드마크로 사용한다.
- 랜드마크 사이는 짙은 붉은색 점선 경로로 연결한다.
- 랜드마크 버튼을 클릭하거나 키보드로 포커스한 뒤 Enter/Space를 누르면 해당 카테고리의 기존 2D 탑다운 월드로 이동한다.
- 상세 월드에서는 기존 WASD/방향키 이동, E키 상호작용, 프로젝트 전시 화면을 유지한다.

## Goals

- 첫 화면에서 다섯 카테고리의 위치와 관계를 즉시 이해할 수 있게 한다.
- 3D 카메라와 원근 겹침을 제거하고, 지도 자체를 게임의 월드 선택 화면으로 만든다.
- 한국어 라벨과 고유한 랜드마크 실루엣으로 카테고리를 구분한다.
- SVG 기반의 반응형 지도와 접근 가능한 DOM 버튼을 함께 제공한다.
- 기존 GitHub Pages 무빌드 구조와 상세 2D 월드를 유지한다.

## Non-goals

- 기존 상세 2D 탐방 월드를 이번 작업에서 다시 만드는 것.
- 외부 이미지나 특정 게임의 지도·아이콘을 복사하는 것.
- 첫 지도에서 별도의 3D 렌더러, 물리 엔진, 복잡한 플레이어 이동을 추가하는 것.
- 실제 포트폴리오 자료 슬롯을 사용자 자료 없이 채우는 것.

## Anti-goals

- 카테고리 이름만 붙인 빈 지도.
- 랜드마크보다 카드 UI가 앞서는 대시보드형 화면.
- 지도 배경과 UI가 서로 다른 시각 언어를 사용하는 구성.

## Approaches

### 선택: SVG 첫 지도 + 기존 Canvas 상세 지도

`src/treasure-map.js`가 양피지 배경, 선화 장식, 경로, 나침반, 랜드마크 SVG와 접근 가능한 버튼을 생성한다. 카테고리 데이터는 `src/content.js`의 지도 좌표와 랜드마크 타입으로 관리하고, 클릭 콜백은 기존 `enterIsland` 상태 전환을 호출한다. 확대·반응형 크기 조절과 포커스 처리가 쉽고, 상세 월드의 Canvas를 재사용할 수 있어 프론트엔드 구조가 명확하다.

### 제외: 전체 Canvas 지도

픽셀 드로잉은 쉽지만 텍스트와 클릭 영역을 별도로 관리해야 하고, 접근성·반응형·키보드 포커스 구현 비용이 커진다.

### 제외: HTML/CSS 타일 지도

DOM 조작은 쉽지만 해안선·산맥·경로처럼 연속적인 지도 선화를 만들기 어렵고, 장식이 카드 레이아웃처럼 보일 가능성이 높다.

## Visual system

- 양피지: `#d8bd79`부터 `#f0d6a0`까지의 따뜻한 베이지
- 잉크: `#4d3424`, 보조 잉크 `#76523a`
- 경로: `#9d6252`, 포커스 `#b84f42`
- 랜드마크 채움: 카테고리별 저채도 색을 사용하되 외곽선은 공통 잉크로 통일
- 지도 장식: 얇은 선화의 산맥·나무·구름·파도·등고선
- 라벨: 지도 위 작은 나무 표지판 또는 리본 형태의 한국어 이름

## Data and interfaces

각 `island`는 다음 지도 필드를 가진다.

```js
map: {
  x: Number,
  y: Number,
  landmark: 'profile' | 'personal' | 'team' | 'external' | 'study',
  label: String,
}
```

`renderTreasureMap({ container, islands, onSelect })`는 `container` 안에 SVG와 버튼을 만들고, 선택된 `island.id`를 `onSelect`으로 전달한다. WebGL 로드나 Three.js CDN이 없어도 첫 화면과 탐방 버튼은 동작해야 한다.

## File boundaries

- `src/treasure-map.js`: 첫 화면 지도 SVG와 랜드마크 상호작용
- `src/content.js`: 다섯 섬의 지도 좌표와 랜드마크 타입
- `src/app.js`: 보물지도 렌더링과 기존 화면 전환 연결
- `index.html`: 3D Canvas 대신 지도 컨테이너 제공
- `src/styles.css`: 양피지 지도, 랜드마크, 반응형·포커스 스타일
- `tests/treasure-map.test.mjs`: 지도 데이터와 렌더링 연결 회귀 테스트
- `README.md`: 첫 화면 구조와 실행 흐름 기록

## Constraints

- 외부 번들러와 새 런타임 의존성을 추가하지 않는다.
- GitHub Pages 정적 배포를 유지한다.
- 기존 프로젝트 데이터, 자료 슬롯, 상세 2D 월드, WASD/E키 흐름을 깨뜨리지 않는다.
- 지도 장식과 랜드마크는 로컬 SVG 문자열 또는 CSS 도형으로 직접 구성한다.
- `prefers-reduced-motion`에서는 경로와 포커스 장식의 애니메이션을 줄인다.
