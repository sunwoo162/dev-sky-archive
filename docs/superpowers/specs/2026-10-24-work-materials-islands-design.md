# 작업·자료 허브와 보물지도 밀도 보강 디자인

## 의도

프로젝트를 찾는 문제를 해결하는 기존 보물지도에 두 개의 관리 허브를 추가한다. `자료`는 포트폴리오·자기소개서·프로젝트 설명·근거 문서를 모으는 곳이고, `작업`은 이후 AI 작업자와 연결해 개발 진행을 게임처럼 확인하는 본부다. 둘은 개인/팀/대외활동/스터디 프로젝트 분류와 섞이지 않는다.

## 사용자 경험

- 첫 지도에는 기존 5개 허브에 `자료`와 `작업`을 더해 총 7개의 선택 가능한 랜드마크가 보인다.
- `자료`를 선택하면 문서·근거 전시를 탐방하는 기존 2D 월드로 들어간다.
- `작업`을 선택하면 현재는 `연결 대기` 상태의 작업 본부와 임시 작업 큐를 보여준다. 나중에 AI별 상태·작업 로그·완료 결과를 동일한 전시 데이터 계약으로 교체한다.
- 실제 AI 연결이나 가짜 진행률은 이번 범위에 포함하지 않는다.

## 지도 디자인 방향

사용자가 보낸 보물지도 레퍼런스의 양피지 색감, 갈색 잉크 선화, 얇은 격자·테두리, 점선 루트와 나침반을 유지한다. 현재 빈 공간을 줄이기 위해 풍선, 등대, 성, 배, 산맥, 오두막, 표지판, 보석을 인라인 SVG 장식으로 추가한다. 이 장식은 클릭 기능과 분리된 배경 레이어이며, 랜드마크 버튼은 HTML 버튼으로 유지한다.

## 데이터 경계

- 기존 프로젝트 허브: `profile`, `personal`, `team`, `external`, `study`
- 신규 운영 허브: `materials`, `work`
- `materials`와 `work`는 각각 `kind`를 갖고 이후 별도 렌더러/데이터 소스로 확장할 수 있다.
- 자료와 작업의 임시 전시 내용은 실제 문서나 AI 실행 사실처럼 표현하지 않는다.

## 비목표

- 이번 변경에서 AI API, 인증, 실시간 폴링, 서버 저장소를 만들지 않는다.
- 지도 레이아웃을 모달이나 대시보드로 바꾸지 않는다.
- 외부 게임 에셋을 복사하지 않고 로컬 SVG 선화로만 밀도를 보강한다.
